# منصة EduCore التعليمية - نسخة الويب (Web App Platform)

تم بناء وبرمجة هذه المنصة لتكون موقع ويب تفاعلي كامل وسحابي يعمل على أي متصفح (لابتوب، كمبيوتر، آيفون، أندرويد) ومتصل بنفس قاعدة بيانات Firebase الحالية:
`educore-app-a0155`

---

## 🌟 مميزات موقع الويب:
1. **لوحة تحكم المعلم (Teacher Dashboard):**
   - إدارة الطلاب والمجموعات.
   - متابعة نسب الحضور والغياب والإحصائيات الحية.
   - رصد وتعديل بيانات الطلاب.

2. **بوابة الطالب وولي الأمر (Student & Parent Portal):**
   - استعلام سريع ومباشر برقم الطالب أو الهاتف.
   - عرض كارت الطالب والباركود الرقمي للطباعة.
   - استعراض نتائج الامتحانات ونسب الحضور والإنذارات.

3. **ماسح الحضور عبر كاميرا الويب (Web QR Scanner):**
   - إمكانية تشغيل كاميرا اللابتوب أو الهاتف وتسجيل الحضور المباشر بلحظة مسح الكارت دون الحاجة لأجهزة مخصصة.

4. **تزامن حقيقي مع السحابة (Firestore):**
   - أي طالب يتم إضافته أو تسجيل حضوره من خلال الموقع ينعكس فوراً في تطبيق الأندرويد، والعكس صحيح!

---

## 🚀 كيفية تشغيل واستضافة الموقع:

### الطريقة 1: التشغيل المحلي المباشر
- افتح ملف `index.html` في أي متصفح (Google Chrome، Safari، Edge) وسيعمل مباشرة مع السحابة.

### الطريقة 2: الاستضافة المجانية على Firebase Hosting (بضغطة واحدة):
إذا كان لديك أدوات Firebase CLI:
```bash
firebase init hosting
# اختر مجلد web
firebase deploy
```
وسيعطيك رابطاً عالمياً مجانياً مثل: `https://educore-app-a0155.web.app`

### الطريقة 3: داخل Google AI Studio (موقع ويب تفاعلي في المعاينة):
- اضغط على زر **New Project** في AI Studio.
- اختر **Web App** بدلاً من Android App.
- انسخ هذه الملفات أو اطلب إنشاء منصة EduCore للويب وستظهر لك شاشة متصفح تفاعلية مباشرة.
